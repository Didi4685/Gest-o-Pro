# GestãoPro — Controle de Home Office, Férias e Viagens

Sistema web (arquivo único) para escala de Home Office por equipe (IPTU, ISS, Dívida Ativa), controle de férias, viagens e consulta externa individual.

## Como usar
Abra o site publicado (GitHub Pages) ou o arquivo `index.html` no navegador.

## Estrutura do repositório
```
/
├── index.html      # aplicação (página principal)
├── README.md       # este arquivo
└── docs/           # (opcional) manuais e prints
```

## Fluxo de trabalho
1. Crie uma branch para cada mudança: `git checkout -b ajuste-ferias`
2. Faça commits pequenos e claros: `git commit -m "Corrige lista de férias"`
3. Abra um Pull Request e faça o merge na `main`
4. O GitHub Pages publica a `main` automaticamente
